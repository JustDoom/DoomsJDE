DoomsJDE (Doom's Java Development Environment (Name subject to change)) is a Java IDE built in Java.  
The goal is to provide an IDE that is both fast, and does not use a lot of memory, that can then be expanded with plugins
to provide a tailored experience.  
We will also not push AI everywhere through it :)

It is currently in its "very very very" early development stage. Hopefully it will enter its "very very" early development stage.
We want to make it a viable option ASAP so that the IDE can be developed inside of the IDE.

## Requirements
- Java 27
- Linux, Windows, MacOS

## Features
This is a basic feature list we aim to target, but does not include everything that we want or will be added
- [x] Basic edit abilities
- [x] Basic project viewer
- [x] Settings menu
- [x] Basic project selector
- [ ] Keybinds
- [ ] Terminal/Log output
- [x] Built in program run
- [ ] Proper context aware tab complete
- [ ] Find/Replace
- [ ] Debugger/breakpoints
- [ ] Java version manager
- [ ] Wakatime support
- [ ] Markdown preview
- [ ] Plugins
